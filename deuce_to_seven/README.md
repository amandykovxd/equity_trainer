# Лоуболл 2-7 (трипл-дро)

Дро-покер, где побеждает слабейшая рука, но стриты и флеши считаются; лучшая рука — 7-5-4-3-2.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 5 |
| Общих карт | нет |
| Колода | 52 карты |
| Кто побеждает | побеждает слабейшая рука |
| Круги ставок | до 1-й замены, после 1-й, после 2-й, после 3-й |
| За столом | 2-6 игроков |

## Чем эта игра отличается

Дро-покер, где побеждает слабейшая рука, но система оценки совсем не та,
что в раззе:

* туз — **старшая** карта, то есть для лоу худшая;
* стриты и флеши **считаются** и портят руку;
* лучшая возможная рука — 7-5-4-3-2 разных мастей.

Поэтому 6-5-4-3-2 хуже, чем 7-5-4-3-2: это стрит. И связанные карты здесь
не ценность, а помеха. Версия с тремя кругами замены называется трипл-дро.

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py 27 terms`.

* **Лоуболл 2-7** — Пятикарточный дро, в котором побеждает самая слабая рука по системе 2-7.
* **Пэт** — Отказаться от замены карт в дро-покере — то есть заявить, что рука уже собрана.
* **Дро** — Недособранная рука, которой не хватает карты до сильной комбинации.
* **Фиксированный лимит** — Размер ставок жёстко задан правилами, повышать произвольно нельзя.
