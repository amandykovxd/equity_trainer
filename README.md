# Покерный тренажёр: все разновидности покера с нуля

Обучающие калькуляторы equity и тренажёры для девяти разновидностей покера.
Рассчитано на человека, который не знает ни одной комбинации и ни одного
термина.

Нужен только Python 3 (проверено на 3.9), никаких зависимостей.

```bash
cd "equity calculator"
python3 poker.py
```

Если вы в покере с полного нуля — начните с этого:

```bash
python3 poker.py start      # маршрут обучения по шагам
python3 poker.py terms      # словарь: 152 термина
```

## Словарь терминов

Поскольку терминов в покере много и половина из них — английские слова
в русской записи, в проекте есть словарь на 152 термина с объяснением
каждого: [GLOSSARY.md](GLOSSARY.md).

```bash
python3 poker.py terms                      # содержание по группам
python3 poker.py terms аутсы                # объяснить один термин
python3 poker.py terms --group Математика   # группу целиком
python3 poker.py terms --all                # весь словарь
python3 poker.py holdem terms               # только термины холдема
```

Словарь и `GLOSSARY.md` собираются из одного файла `core/glossary.py`,
поэтому разойтись они не могут.

Группы: Основы, Карты и борд, Комбинации, Ход раздачи, Позиции,
Действия и ставки, Математика, Дро и аутсы, Стратегия, Форматы игры,
Разновидности покера, Термины отдельных игр, Жаргон и психология.

## Где играть бесплатно

Честная оговорка: страницы этих сайтов я не смог открыть из своего
окружения (нет доступа в сеть), поэтому список составлен по поисковым
результатам и общеизвестной репутации — **проверьте условия сами**,
прежде чем регистрироваться. Отдельно проверьте, доступен ли сервис
в вашем регионе.

| Сервис | Что это | Регистрация |
|---|---|---|
| **PokerNow** (pokernow.club) | Приватные столы в браузере: создаёте стол, кидаете ссылку друзьям. Игровые фишки бесплатны и не имеют ценности | Не нужна |
| **Replay Poker** (replaypoker.com) | Публичные столы и турниры только на условные фишки. Реальных денег в игре нет вообще | Нужна |
| **PokerStars Play** | Приложение/клиент крупнейшего рума с условными фишками. Удобно тем, что интерфейс тот же, что в реальных играх | Нужна |
| **PokerTH** (pokerth.net) | Открытая бесплатная программа, игра против ботов офлайн | Не нужна |
| **888poker / partypoker / GGPoker** | У всех крупных румов есть столы на условные фишки внутри клиента | Нужна |

Что имеет смысл выбрать именно вам:

1. **Начните с PokerTH или ботов** — вы сможете спокойно, без спешки
   и без чужого раздражения, посмотреть, как выглядит раздача, и сверяться
   со шпаргалкой комбинаций.
2. **Потом Replay Poker или PokerNow** — там живые люди, но ставки ничего
   не стоят.
3. **На реальные деньги не садитесь**, пока не пройдёте уроки холдема
   и не начнёте стабильно отвечать правильно в тренажёре «колл или фолд».

Важное предупреждение про условные фишки: на них играют совсем не так, как
на деньги. Люди идут олл-ин с мусором, потому что терять нечего. Это нормально
для изучения комбинаций и механики, но привычки формируются плохие —
не удивляйтесь, что на реальных ставках игра выглядит иначе.

Разновидности редких игр (разз, бадуги, 2-7) на бесплатных столах найти
трудно: их почти не запускают. Зато их удобно изучать здесь — тренажёр
раздаёт ситуации сам.

## Про скрипты и правила румов

**Использование калькуляторов, HUD и любых подсказчиков во время игры
запрещено** правилами практически всех легальных покер-румов, и за это
блокируют аккаунт вместе с балансом.

Этот проект на такое и не способен: он не подключается ни к одному руму,
ничего не считывает с экрана и не следит за реальной раздачей. Это тренажёр
для работы **между** сессиями — вы разбираете на нём ситуации, а за столом
пользуетесь уже своей головой. Ровно для этого в уроках и даётся «правило
2 и 4», которое считается в уме за секунду.

## Маршрут обучения

Подробная версия — `python3 poker.py start`. Коротко:

| Шаг | Что делать | Команда |
|---|---|---|
| 1 | Термины: группы «Основы», «Карты и борд», «Комбинации» | `python3 poker.py terms` |
| 2 | Правила холдема | `python3 poker.py holdem lesson 1` |
| 3 | Комбинации — выучить наизусть | `python3 poker.py holdem lesson 2` |
| 4 | Узнавать комбинации до автоматизма | `python3 poker.py holdem quiz combos` |
| 5 | Определять победителя на вскрытии | `python3 poker.py holdem quiz showdown` |
| 6 | Что такое equity | `python3 poker.py holdem lesson 3` |
| 7 | Аутсы и правило 2 и 4 | `python3 poker.py holdem lesson 4` |
| 8 | Пот-оддсы | `python3 poker.py holdem lesson 5` |
| 9 | Главное упражнение: колл или фолд | `python3 poker.py holdem drill` |
| 10 | Стартовые руки и позиция | `python3 poker.py holdem lesson 6` |
| 11 | Типичные ошибки новичка | `python3 poker.py holdem lesson 7` |
| 12 | Только теперь — другие разновидности | `python3 poker.py list` |

Шаги 4-5 стоит повторять несколько дней подряд по пять минут: узнавание
комбинаций должно стать мгновенным, иначе за столом не останется внимания
ни на что другое.

## Калькулятор equity

Карты записываются как номинал + масть:

```
Номиналы: 2 3 4 5 6 7 8 9 T J Q K A      (T или 10 — десятка)
Масти:    s = пики ♠   h = червы ♥   d = бубны ♦   c = трефы ♣
Примеры:  As = туз пик,  Th = десятка червей,  7d = семёрка бубен
```

Холдем — ваша рука против известной руки соперника, с разбором колла:

```bash
python3 poker.py holdem equity 9h8h --board Kh7h2c --vs KsQd --pot 100 --bet 50
```

```
Сейчас у вас: Старшая карта — король
У соперника:  Пара королей

Ваша equity: 39.8%   (точный перебор)
Аутсов: 9 — A♥ Q♥ J♥ T♥ 6♥ 5♥ 4♥ 3♥ 2♥
Правило 4: 9 × 4 = 36%

Требуемая equity: 33.3%   (50 / 150)
✓ Колл выгоден (+6.5 п.п. equity сверх требуемой).
```

Хай-лоу — видно обе половины банка:

```bash
python3 poker.py o8 equity As2d3h4c --board 5h6c7s --vs KsKhQdJc
```

```
Сейчас у вас: Хай: Стрит до семёрки  |  Лоу 7-6-5-2-A
У соперника:  Хай: Пара королей      |  Лоу не собрано

Ваша equity: 98.3%
  хай-половина: 96.6%   лоу-половина: 100.0%
  забрали весь банк («скуп»): 96.6%
```

Другие примеры:

```bash
python3 poker.py plo equity AsAhKsKh --opponents 3     # против 3 случайных рук
python3 poker.py razz equity As2d3h --vs 5s6d7h        # лоу против лоу
python3 poker.py badugi hand 4s3h2d2c                  # что это за рука
python3 poker.py shortdeck lesson 2                    # частоты комбинаций
python3 poker.py test                                  # самопроверка
```

## Насколько можно доверять числам

Один движок считает все девять разновидностей и выбирает способ сам:

* **точный перебор** — когда вариантов борда немного (до 150 000);
* **Монте-Карло** — когда вариантов миллионы. Погрешность при 20-25 тысячах
  раздач порядка ±0.3 п.п.

Эталонные значения проверены полным перебором всех 1 712 304 вариантов борда
и совпадают с таблицами equity из покерной литературы:

| Ситуация | Equity (точный перебор) |
|---|---|
| AA против KK | 81.95% |
| AKs против 22 | 50.08% |
| AKo против QQ | 43.65% |
| AA против KK и QQ | 67.45% |

```bash
python3 selftest.py          # или python3 poker.py test
```

540 проверок за полторы секунды: порядок комбинаций во всех девяти играх,
кикеры, «колесо» A-2-3-4-5, выбор лучших пяти карт из семи, правило «ровно
две карты» в омахе, квалификация лоу, сравнение лоу-систем A-5 / 2-7 /
бадуги, деление банка в хай-лоу, совпадение Монте-Карло с точным перебором,
счёт аутсов, арифметика пот-оддсов, разбор ввода и целостность словаря.

Два инварианта проверяются для каждой игры отдельно: доли банка всегда
складываются в единицу, и сумма equity всех игроков тоже равна единице.

## Из чего состоит проект

```
poker.py              общий вход: выбор игры, словарь, маршрут обучения
selftest.py           540 проверок расчётов
GLOSSARY.md           словарь терминов (собирается из core/glossary.py)

core/                 общий движок — не зависит от разновидности
  cards.py            карты, колоды (52 и 36), парсинг, вывод
  evaluator.py        сила обычной комбинации (быстрая оценка 5-7 карт)
  lowball.py          лоу-системы: A-5, 8 or better, 2-7, бадуги
  variant.py          описание правил разновидности
  equity.py           equity, аутсы, пот-оддсы для любой игры
  calculator.py       разбор ситуации: equity + аутсы + решение
  drills.py           квизы и тренажёры, работающие во всех играх
  cli.py              меню и команды, общие для всех разновидностей
  glossary.py         152 термина
  ui.py               вывод в терминал

texas_holdem/         по папке на разновидность; внутри у каждой
omaha/                  rules.py              правила и оценка рук
omaha_hi_lo/            equity_calculator.py  калькулятор и точка входа
short_deck/             lessons.py            уроки
five_card_draw/         README.md             описание игры
seven_card_stud/
razz/                 у холдема дополнительно:
deuce_to_seven/         ranges.py   169 стартовых рук
badugi/                 drills.py   квизы на аутсы и стартовые руки
```

Правила каждой игры описываются одним объектом `Variant`: сколько карт
на руках, есть ли общие карты, какая колода, побеждает сильнейшая рука
или слабейшая. Поэтому движок equity, квизы и меню написаны один раз
и работают для всех девяти разновидностей — а в папке каждой игры лежит
только то, что действительно своё.
