# Бадуги

4 карты, побеждает самая низкая рука из карт разных мастей и разных достоинств; лучшая — 4-3-2-a.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 4 |
| Общих карт | нет |
| Колода | 52 карты |
| Кто побеждает | побеждает слабейшая рука |
| Круги ставок | до 1-й замены, после 1-й, после 2-й, после 3-й |
| За столом | 2-6 игроков |

## Чем эта игра отличается

Четыре карты, общих карт нет, побеждает самая низкая рука, в которой все
карты **разных мастей и разных достоинств**. Такая рука из четырёх карт
называется «бадуги», из трёх — «снаут», и любое бадуги бьёт любой снаут.

Туз — младшая карта, лучшая возможная рука — 4-3-2-A всех четырёх мастей.
Правил здесь меньше, чем в холдеме, но привычная логика не работает совсем.

## Уроки

1. Правила бадуги — `python3 poker.py badugi lesson 1`
2. Как сравнивают руки — `python3 poker.py badugi lesson 2`
3. Замена и базовая стратегия — `python3 poker.py badugi lesson 3`

Все подряд: `python3 poker.py badugi lesson all`

## Команды

Запуск без аргументов открывает меню:

```bash
python3 badugi/equity_calculator.py
# или короче:
python3 poker.py badugi
```

| Команда | Что делает |
|---|---|
| `equity <карты>` | посчитать equity; `--vs`, `--board`, `--opponents`, `--pot`, `--bet` |
| `hand <карты>` | назвать комбинацию |
| `lesson <N>` | открыть урок |
| `quiz showdown` | квиз: кто выиграл банк |
| `terms` | термины этой игры |

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py badugi terms`.

* **Бадуги** — 4 карты, замены, и побеждает самая низкая рука, в которой все четыре карты разных мастей И разных достоинств.
* **Снаут** — Рука в бадуги из трёх подходящих карт — то есть бадуги не собралось.
* **Пэт** — Отказаться от замены карт в дро-покере — то есть заявить, что рука уже собрана.
* **Дро** — Недособранная рука, которой не хватает карты до сильной комбинации.
