# Техасский холдем

2 своих карты, 5 общих, лучшая комбинация из 7 — самая популярная игра в мире.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 2 |
| Общих карт | 5 |
| Колода | 52 карты |
| Кто побеждает | побеждает сильнейшая комбинация |
| Круги ставок | префлоп, флоп, тёрн, ривер |
| За столом | 2-9 игроков |

## Чем эта игра отличается

Самая популярная разновидность покера и единственная, с которой стоит
начинать с нуля. Комбинация собирается из любых пяти карт среди ваших двух
и пяти общих — можно использовать обе свои карты, одну или ни одной.

Здесь же лежит то, чего нет у других разновидностей: таблица всех 169
стартовых рук, квиз на счёт аутсов и квиз на стартовые руки.

## Уроки

1. Как идёт раздача (правила холдема) — `python3 poker.py holdem lesson 1`

3. Equity — что это и зачем — `python3 poker.py holdem lesson 3`
4. Аутсы и правило 2 и 4 — `python3 poker.py holdem lesson 4`
5. Пот-оддсы: считаем колл — `python3 poker.py holdem lesson 5`
6. Стартовые руки и позиция — `python3 poker.py holdem lesson 6`
7. Типичные ошибки новичка — `python3 poker.py holdem lesson 7`

Все подряд: `python3 poker.py holdem lesson all`

## Команды

Запуск без аргументов открывает меню:

```bash
python3 texas_holdem/equity_calculator.py
# или короче:
python3 poker.py holdem
```

| Команда | Что делает |
|---|---|
| `equity <карты>` | посчитать equity; `--vs`, `--board`, `--opponents`, `--pot`, `--bet` |
| `hand <карты>` | назвать комбинацию |
| `lesson <N>` | открыть урок |
| `quiz showdown` | квиз: кто выиграл банк |
| `quiz combos` | квиз: назови комбинацию |
| `drill` | тренажёр: колл или фолд |
| `terms` | термины этой игры |
| `chart` | таблица всех 169 стартовых рук |
| `outs` | квиз: посчитать аутсы |
| `preflop` | квиз: играть стартовую руку или сбросить |

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py holdem terms`.

* **Техасский холдем** — 2 карманные карты, 5 общих. Комбинация — лучшие 5 карт из 7. Самая популярная разновидность покера в мире.
* **Карманные карты** — Ваши личные закрытые карты, которых не видит никто.
* **Борд** — Общие карты, выложенные в центр стола. Они принадлежат всем игрокам одновременно.
* **Кикер** — Карта, не входящая в саму комбинацию, но решающая спор при равных комбинациях.
* **Аутсы** — Карты, которые превращают вашу проигрывающую руку в выигрывающую.
* **Пот-оддсы** — Минимальная equity, при которой колл перестаёт терять деньги.
