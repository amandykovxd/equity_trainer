# Разз

Стад, где побеждает самая слабая рука; лучшая рука — 5-4-3-2-a.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 7 |
| Общих карт | нет |
| Колода | 52 карты |
| Кто побеждает | побеждает слабейшая рука |
| Круги ставок | 3-я улица, 4-я улица, 5-я улица, 6-я улица, 7-я улица |
| За столом | 2-8 игроков |

## Чем эта игра отличается

Семикарточный стад наоборот: банк забирает самая слабая рука по системе A-5.

* туз — младшая карта;
* стриты и флеши не считаются вообще;
* пары, тройки и каре портят руку;
* лучшая возможная рука — 5-4-3-2-A («колесо»).

Самое трудное здесь для новичка — переучить рефлекс: пара тузов в раззе
не «сильная рука», а катастрофа, она хуже короля-девятки без пары.

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py razz terms`.

* **Разз** — Семикарточный стад наоборот: побеждает самая СЛАБАЯ рука по системе A-5.
* **Нат-лоу** — Сильнейшее возможное лоу при данном борде.
* **Колесо** — Стрит A-2-3-4-5, где туз работает как единица.
* **Дор-карта** — Первая открытая карта игрока в стад-играх.
* **Бринг-ин** — Обязательная первая ставка в стад-игре, которую делает игрок с определённой открытой картой.
* **Мёртвые карты** — Карты, которые вы видели в открытых руках соперников, — значит, их больше нет в колоде.
