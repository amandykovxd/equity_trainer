# Пятикарточный дро

5 закрытых карт и замена; общих карт нет — самые простые правила.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 5 |
| Общих карт | нет |
| Колода | 52 карты |
| Кто побеждает | побеждает сильнейшая комбинация |
| Круги ставок | до замены, после замены |
| За столом | 2-6 игроков |

## Чем эта игра отличается

Самые простые правила в покере: пять закрытых карт, круг ставок, замена
любого числа карт, ещё круг ставок, вскрытие. Общих карт нет. Комбинации
обычные.

Информации о сопернике почти нет — только сколько карт он поменял. Поменял
три, скорее всего держал пару; не менял вовсе («стоит пэт») — заявляет
готовую руку. Урок 2 считает на настоящих числах, сколько карт выгоднее
менять.

## Уроки

1. Самые простые правила в покере — `python3 poker.py draw lesson 1`
2. Сколько карт менять — `python3 poker.py draw lesson 2`
3. Базовая стратегия — `python3 poker.py draw lesson 3`

Все подряд: `python3 poker.py draw lesson all`

## Команды

Запуск без аргументов открывает меню:

```bash
python3 five_card_draw/equity_calculator.py
# или короче:
python3 poker.py draw
```

| Команда | Что делает |
|---|---|
| `equity <карты>` | посчитать equity; `--vs`, `--board`, `--opponents`, `--pot`, `--bet` |
| `hand <карты>` | назвать комбинацию |
| `lesson <N>` | открыть урок |
| `quiz showdown` | квиз: кто выиграл банк |
| `quiz combos` | квиз: назови комбинацию |
| `terms` | термины этой игры |

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py draw terms`.

* **Пятикарточный дро** — 5 закрытых карт, затем один или несколько кругов замены карт. Общих карт нет.
* **Пэт** — Отказаться от замены карт в дро-покере — то есть заявить, что рука уже собрана.
* **Дро** — Недособранная рука, которой не хватает карты до сильной комбинации.
* **Блеф** — Ставка со слабой рукой в расчёте, что соперник сбросит лучшую.
