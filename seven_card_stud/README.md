# Семикарточный стад

Общих карт нет: у каждого свои 7 карт, часть из них открыта для всех.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 7 |
| Общих карт | нет |
| Колода | 52 карты |
| Кто побеждает | побеждает сильнейшая комбинация |
| Круги ставок | 3-я улица, 4-я улица, 5-я улица, 6-я улица, 7-я улица |
| За столом | 2-8 игроков |

## Чем эта игра отличается

Общих карт нет совсем: у каждого свои семь карт, и комбинация собирается
только из них. Четыре карты из семи раздаются открыто, поэтому вы видите
часть чужих рук.

Отсюда главный навык стада — счёт мёртвых карт: если нужные вам карты уже
лежат в открытых руках соперников, ваше дро мертво, сколько бы аутсов
ни казалось по учебнику. Играется обычно с анте и фиксированным лимитом.

## Уроки

1. Как идёт раздача в стаде — `python3 poker.py stud lesson 1`
2. Мёртвые карты — главный навык — `python3 poker.py stud lesson 2`
3. С чем играть первые три карты — `python3 poker.py stud lesson 3`

Все подряд: `python3 poker.py stud lesson all`

## Команды

Запуск без аргументов открывает меню:

```bash
python3 seven_card_stud/equity_calculator.py
# или короче:
python3 poker.py stud
```

| Команда | Что делает |
|---|---|
| `equity <карты>` | посчитать equity; `--vs`, `--board`, `--opponents`, `--pot`, `--bet` |
| `hand <карты>` | назвать комбинацию |
| `lesson <N>` | открыть урок |
| `quiz showdown` | квиз: кто выиграл банк |
| `quiz combos` | квиз: назови комбинацию |
| `drill` | тренажёр: колл или фолд |
| `terms` | термины этой игры |

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py stud terms`.

* **Семикарточный стад** — Общих карт нет: каждый получает свои 7 карт, часть из них открыто. Комбинация — лучшие 5 из этих 7.
* **Дор-карта** — Первая открытая карта игрока в стад-играх.
* **Бринг-ин** — Обязательная первая ставка в стад-игре, которую делает игрок с определённой открытой картой.
* **Мёртвые карты** — Карты, которые вы видели в открытых руках соперников, — значит, их больше нет в колоде.
* **Анте** — Обязательная ставка, которую вносят все игроки, а не только двое.
* **Фиксированный лимит** — Размер ставок жёстко задан правилами, повышать произвольно нельзя.
