# Омаха хай-лоу (Omaha/8)

Омаха, где банк делится между сильнейшей рукой и слабейшей (если лоу вообще собралось).

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 4 |
| Общих карт | 5 |
| Колода | 52 карты |
| Кто побеждает | банк делится между сильнейшей и слабейшей рукой |
| Круги ставок | префлоп, флоп, тёрн, ривер |
| За столом | 2-9 игроков |

## Чем эта игра отличается

Это омаха, в которой банк делится на две половины. Половина уходит
сильнейшей комбинации, половина — слабейшей руке по системе A-5. Но лоу
считается собранным только если есть пять **разных** карт достоинством
8 или ниже; иначе весь банк забирает хай.

Хай и лоу можно собирать разными парами своих карт — правило «ровно две»
применяется к каждой половине отдельно. Забрать обе половины называется
«скуп», и именно к этому здесь стремятся.

## Уроки

1. Делёж банка: хай и лоу — `python3 poker.py o8 lesson 1`
2. Скуп — то, ради чего здесь играют — `python3 poker.py o8 lesson 2`
3. Каунтерфейт: как лоу теряет ценность — `python3 poker.py o8 lesson 3`

Все подряд: `python3 poker.py o8 lesson all`

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py o8 terms`.

* **Омаха хай-лоу** — Омаха, в которой банк делится между сильнейшей рукой (хай) и слабейшей (лоу).
* **Правило «ровно две карты»** — В омахе комбинация обязательно состоит из двух ваших карт и трёх общих — не больше и не меньше.
* **Квалификация лоу** — Условие, при котором лоу-рука вообще считается собранной: пять разных карт достоинством 8 или ниже.
* **Скуп** — Забрать обе половины банка — и хай, и лоу — одной рукой.
* **Нат-лоу** — Сильнейшее возможное лоу при данном борде.
* **Каунтерфейт** — Карта, которая обесценивает уже собранную руку.
* **Сплит** — Банк делится между игроками с одинаково сильными руками.
* **Колесо** — Стрит A-2-3-4-5, где туз работает как единица.
