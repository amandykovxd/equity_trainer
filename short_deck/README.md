# Шортдек-холдем

Холдем на 36 картах, где флеш сильнее фулл-хауса, а тройка сильнее стрита.

## Правила в двух строках

| | |
|---|---|
| Карт на руках | 2 |
| Общих карт | 5 |
| Колода | 36 карт |
| Кто побеждает | побеждает сильнейшая комбинация |
| Круги ставок | префлоп, флоп, тёрн, ривер |
| За столом | 2-9 игроков |

## Чем эта игра отличается

Холдем на колоде из 36 карт: всё младше шестёрки убрано. Из-за этого
меняется редкость комбинаций, а значит и порядок старшинства:

* **флеш сильнее фулл-хауса** (в масти 9 карт вместо 13);
* **тройка сильнее стрита** (карты идут плотнее, стриты собираются чаще);
* младший стрит — A-6-7-8-9, туз в нём работает как пятёрка.

Урок 2 не берёт эти правила на веру: он раздаёт 40 000 случайных рук
из обеих колод и показывает реальные частоты комбинаций.

## Уроки

1. Короткая колода и новый порядок комбинаций — `python3 poker.py shortdeck lesson 1`
2. Почему порядок именно такой (считаем частоты) — `python3 poker.py shortdeck lesson 2`
3. Как меняется сама игра — `python3 poker.py shortdeck lesson 3`

Все подряд: `python3 poker.py shortdeck lesson all`

## Команды

Запуск без аргументов открывает меню:

```bash
python3 short_deck/equity_calculator.py
# или короче:
python3 poker.py shortdeck
```

| Команда | Что делает |
|---|---|
| `equity <карты>` | посчитать equity; `--vs`, `--board`, `--opponents`, `--pot`, `--bet` |
| `hand <карты>` | назвать комбинацию |
| `lesson <N>` | открыть урок |
| `quiz showdown` | квиз: кто выиграл банк |
| `quiz combos` | квиз: назови комбинацию |
| `drill` | тренажёр: колл или фолд |
| `terms` | термины этой игры |

## Ключевые термины

Полный словарь — в [GLOSSARY.md](../GLOSSARY.md), из терминала `python3 poker.py shortdeck terms`.

* **Шортдек** — Холдем на короткой колоде из 36 карт: все карты младше шестёрки убраны. Порядок комбинаций из-за этого меняется.
* **Техасский холдем** — 2 карманные карты, 5 общих. Комбинация — лучшие 5 карт из 7. Самая популярная разновидность покера в мире.
* **Аутсы** — Карты, которые превращают вашу проигрывающую руку в выигрывающую.
* **Пот-оддсы** — Минимальная equity, при которой колл перестаёт терять деньги.
